カスタム Request と APIRoute クラスの拡張

APIRoute.get_route_handler() と Starlette の Request をサブクラス化すると、ルーターのパス照合が成功した直後かつ FastAPI が JSON デコードや Pydantic 検証を実行する直前に処理を挟み込むことができ、ルーター単位での透過的 gzip 解凍・生バイト列に対する HMAC 署名検証・オペレーション別レイテンシ計測・構造化 422 エラー拡張を実現できます。

FastAPI で横断的関心事を実装する際は、ASGI ライフサイクルのどの時点で介入する必要があるか、そしてどの範囲のルーターに適用すべきかに応じて拡張フックを選択します。

1. ASGI ミドルウェアと APIRoute.get_route_handler() のライフサイクル

fastapi/routing.py では、APIRouter に登録される各パスオペレーションが APIRoute（または APIRouter(route_class=...) に指定したカスタムサブクラス）を生成し、self.app = request_response(self.get_route_handler()) を構築します。さらに子ルーターを app.include_router() で統合する際も、_EffectiveRouteContext.from_api_route() が _effective_route_context_var を設定したうえで統合コンテキストごとに一度だけ original_route.get_route_handler() を再呼び出しするため、親ルーターから継承したプレフィックスや依存関係を含むハンドラを確実にラップでき、他の兄弟ルーターには一切影響を与えません。

特に重要なのが、get_request_handler()（fastapi/routing.py）内部の実行順序です。

  1. ボディ読み取りと JSON デコード（await request.body() / await request.json()）が最初に実行され、JSON 構文が不正な場合は即座に RequestValidationError(type="json_invalid") が送出されます。
  2. 依存関係の解決（await solve_dependencies(...)）はその後に実行されます。したがって、Depends() 関数では request.json() が失敗する前に gzip 圧縮ストリームを解凍することはできず、ボディやパラメータ検証が送出する RequestValidationError を捕捉することもできません。
比較軸 グローバル純粋 ASGI ミドルウェア APIRouter(route_class=CustomRoute) Depends() / Security()
実行タイミング ルーティング前（404・/static・全ルーターで常時実行） APIRoute.matches() 成功後、JSON 解析および Depends() の直前 get_request_handler() による JSON／Form 解析の後
適用スコープの粒度 FastAPI アプリ全体（またはマウントされたサブアプリ） 対象の APIRouter サブツリーのみ（route_class=...） アプリ・APIRouter・ルート dependencies・個別引数
Request（body()）の差し替え 低レベル ASGI receive ラッパーの手動実装が必要 ネイティブ対応（CustomRequest(request.scope, request.receive)） 不可（すでに request.json() が実行済み）
RequestValidationError の捕捉 不可（外側の ExceptionMiddleware 等で一括処理） 可能（try: await original_route_handler(request) で捕捉） 不可（solve_dependencies() 完了後に送出されるため）
ルートメタデータへの参照 ルーティング前のため scope["route"] 未確定 self.operation_id・self.path・self.tags・self.dependant を直接参照 request.scope["route"] 経由のみ

2. 透過的 GzipRequest・422 エラー拡張・Webhook HMAC 検証ルート

カスタム Request サブクラスとカスタム APIRoute を組み合わせることで、各エンドポイントの関数署名を一切汚さずにストリーム変換や暗号学的署名検証を組み込めます。

上限付き GzipRequest と GzipRoute による透過解凍

Starlette の Request.json() は内部で await self.body() を呼び出し、結果を self._body にキャッシュします。GzipRequest で async def body(self) -> bytes をオーバーライドし、無制限な gzip.decompress() ではなく gzip.GzipFile.read(MAX_DECOMPRESSED_BYTES + 1) で展開バイト数に上限を設けることで、gzip 圧縮爆弾（DoS）を 413 Content Too Large で遮断しつつ、解凍済み UTF-8 JSON を get_request_handler() へ透過的に引き渡せます。

import gzip
import io
from typing import Any, Callable, Coroutine

from fastapi import APIRouter, FastAPI, HTTPException, Request, Response, status
from fastapi.routing import APIRoute
from pydantic import BaseModel

MAX_DECOMPRESSED_BYTES = 1024 * 1024  # 1 MiB decompression ceiling against zip bombs


class GzipRequest(Request):
    async def body(self) -> bytes:
        if not hasattr(self, "_body"):
            raw_body = await super().body()
            encodings = [
                token.strip().lower()
                for header in self.headers.getlist("Content-Encoding")
                for token in header.split(",")
            ]
            if "gzip" in encodings:
                try:
                    with gzip.GzipFile(fileobj=io.BytesIO(raw_body)) as gz_stream:
                        decompressed = gz_stream.read(MAX_DECOMPRESSED_BYTES + 1)
                except (OSError, EOFError) as exc:
                    raise HTTPException(
                        status_code=status.HTTP_400_BAD_REQUEST,
                        detail="Malformed gzip request stream",
                    ) from exc
                if len(decompressed) > MAX_DECOMPRESSED_BYTES:
                    raise HTTPException(
                        status_code=status.HTTP_413_CONTENT_TOO_LARGE,
                        detail="Decompressed payload exceeds 1 MiB limit",
                    )
                raw_body = decompressed
            self._body = raw_body
        return self._body


class GzipRoute(APIRoute):
    def get_route_handler(self) -> Callable[[Request], Coroutine[Any, Any, Response]]:
        original_route_handler = super().get_route_handler()

        async def custom_route_handler(request: Request) -> Response:
            gzip_request = GzipRequest(request.scope, request.receive)
            return await original_route_handler(gzip_request)

        return custom_route_handler


app = FastAPI(title="Telemetry Ingest API", version="1.0.0")
ingest_router = APIRouter(prefix="/ingest", route_class=GzipRoute)


class MetricBatch(BaseModel):
    service: str
    samples: list[float]


@ingest_router.post("/metrics")
async def ingest_metrics(batch: MetricBatch) -> dict[str, Any]:
    return {
        "service": batch.service,
        "count": len(batch.samples),
        "sum": sum(batch.samples),
    }


@app.get("/healthz")

    return {"status": "ok"}

レイテンシ計測・構造化 422 ラッピング・HMAC-SHA256 署名検証

Webhook 受信エンドポイントでは、JSON デシリアライズを実行する前に、受信した生のバイト列に対して定数時間比較 hmac.compare_digest() で X-Hub-Signature-256 を検証する必要があります。これにより、偽造されたリクエストに対してスキーマ解析の CPU コストを消費したり内部検証エラーを漏洩したりすることなく 401 Unauthorized で即座に拒否できます。さらに同じ APIRoute サブクラス内で await original_route_handler(request) をラップすれば、X-Response-Time-Ms ヘッダの付与と、正規送信元のスキーマ不整合（RequestValidationError）に対する operation_id および長さ制限付き生ボディプレビューを含む構造化 422 応答を同時に実装できます。

import hashlib
import hmac
import logging
import os
import secrets
import time
from typing import Any, Callable, Coroutine

from fastapi import APIRouter, FastAPI, HTTPException, Request, Response, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from fastapi.routing import APIRoute
from pydantic import BaseModel, Field

logger = logging.getLogger(__name__)


def load_webhook_secret() -> bytes:
    configured = os.environ.get("WEBHOOK_HMAC_SECRET")
    if configured:
        return configured.encode("utf-8")
    logger.warning("WEBHOOK_HMAC_SECRET unset; using ephemeral instance-isolated key")
    return secrets.token_bytes(32)


WEBHOOK_SECRET: bytes = load_webhook_secret()
MAX_PREVIEW_CHARS = 256


class HmacTimedRoute(APIRoute):
    def get_route_handler(self) -> Callable[[Request], Coroutine[Any, Any, Response]]:
        original_route_handler = super().get_route_handler()
        operation_id = self.operation_id or self.name

        async def custom_route_handler(request: Request) -> Response:
            started = time.perf_counter()

            # 1. Verify HMAC-SHA256 over raw bytes BEFORE Pydantic parses JSON
            raw_body = await request.body()
            provided_sig = request.headers.get("X-Hub-Signature-256", "")
            expected_sig = (
                "sha256="
                + hmac.new(WEBHOOK_SECRET, raw_body, hashlib.sha256).hexdigest()
            )
            if not hmac.compare_digest(expected_sig, provided_sig):
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Invalid or missing X-Hub-Signature-256 header",
                )

            # 2. Execute inner FastAPI handler & catch RequestValidationError
            try:
                response = await original_route_handler(request)
            except RequestValidationError as exc:
                elapsed_ms = (time.perf_counter() - started) * 1000.0
                preview = raw_body.decode("utf-8", errors="replace")[:MAX_PREVIEW_CHARS]
                return JSONResponse(
                    status_code=status.HTTP_422_UNPROCESSABLE_CONTENT,
                    content={
                        "operation_id": operation_id,
                        "detail": exc.errors(),
                        "raw_body_preview": preview,
                    },
                    headers={"X-Response-Time-Ms": f"{elapsed_ms:.2f}"},
                )

            elapsed_ms = (time.perf_counter() - started) * 1000.0
            response.headers["X-Response-Time-Ms"] = f"{elapsed_ms:.2f}"
            return response

        return custom_route_handler


app = FastAPI(title="Signed Webhook Receiver", version="1.0.0")
webhook_router = APIRouter(prefix="/webhooks", route_class=HmacTimedRoute)


class PaymentDeliveredEvent(BaseModel):
    event_id: str
    invoice_id: str
    amount_cents: int = Field(gt=0)


@webhook_router.post("/payments")
async def receive_payment_webhook(
    event: PaymentDeliveredEvent,
) -> dict[str, Any]:
    return {"accepted": True, "event_id": event.event_id}


app.include_router(webhook_router)

[!TIP] await request.body() は読み取ったバイト列を request._body にキャッシュするため、HmacTimedRoute 内で先に await request.body() を呼び出しても後続の original_route_handler(request) でストリームが枯渇することはなく、get_request_handler() はキャッシュ済みのバイト列を即座に再利用します。ただし数メガバイト規模のマルチパートファイルアップロード（request.stream() から SpooledTemporaryFile へ逐次書き出すルート）では、メモリ一括展開を避けるため Request.body() の事前読み取りを行わないルーターへ分離してください。
